Migration Discourse on X / Twitter

Social media project · 2019–2023

This project collects and analyses over 2.4 million tweets related to migration published between 2019 and 2023 in English, Dutch and Italian. Data was gathered via the Twitter Academic Research API before its closure in early 2023, and subsequently via web scraping of public timelines.

Sentiment analysis (VADER for English, custom fine-tuned models for Dutch and Italian) is combined with topic modelling (LDA) to track how public discourse on migration shifts in response to policy events, media cycles and border incidents. Particular attention is paid to the framing of sea crossings in the central Mediterranean.

The corpus reveals systematic differences in emotional valence across languages and political contexts, with Italian-language content showing the highest volatility in sentiment scores following news events.

Python · Tweepy · VADER 
import tweepy
import pandas as pd
from vaderSentiment.vaderSentiment import SentimentIntensityAnalyzer

client   = tweepy.Client(bearer_token=BEARER_TOKEN, wait_on_rate_limit=True)
analyzer = SentimentIntensityAnalyzer()

query = (
    '(migration OR refugees OR #migrants OR #mediterranean) '
    'lang:en -is:retweet -is:reply'
)

rows = []
for tweet in tweepy.Paginator(
    client.search_recent_tweets,
    query=query,
    tweet_fields=['created_at', 'public_metrics', 'geo'],
    max_results=100
).flatten(limit=5000):

    scores = analyzer.polarity_scores(tweet.text)
    rows.append({
        'id':         tweet.id,
        'text':       tweet.text,
        'created_at': tweet.created_at,
        'retweets':   tweet.public_metrics['retweet_count'],
        'sentiment':  scores['compound'],
    })

df = pd.DataFrame(rows)
df['date'] = pd.to_datetime(df['created_at']).dt.date

# Daily average sentiment
daily = df.groupby('date')['sentiment'].mean()
print(daily.tail(10))
