Neighbourhood Change Index

Geo-spatial project · 2023–ongoing

The Neighbourhood Change Index (NCI) is a composite spatial indicator measuring multi-dimensional socioeconomic and demographic transformation at the sub-district level. The index is currently computed for Amsterdam and Antwerp using decennial census data (2011 and 2021).

Four dimensions are standardised and aggregated: median household income, share of foreign-born residents, rental housing proportion, and tertiary education attainment. Principal component analysis is used to weight each dimension according to its explanatory power.

Preliminary results show that gentrification and migrant concentration are increasingly co-occurring processes rather than mutually exclusive — with significant implications for housing policy and integration programmes.

Python · Scikit-learn · GeoPandas

import geopandas as gpd
import numpy as np
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

# Load census data for two time points
df_2011 = gpd.read_file('data/census_amsterdam_2011.geojson')
df_2021 = gpd.read_file('data/census_amsterdam_2021.geojson')

indicators = [
    'income_median',
    'foreign_born_pct',
    'rental_pct',
    'edu_tertiary_pct'
]

# Compute absolute change between census waves
delta = df_2021[indicators].values - df_2011[indicators].values

# Standardise and reduce dimensions
scaler = StandardScaler()
delta_scaled = scaler.fit_transform(delta)

pca = PCA(n_components=1)
df_2021['NCI'] = pca.fit_transform(delta_scaled)

print(f'Variance explained: {pca.explained_variance_ratio_[0]:.2%}')

# Map the index
df_2021.plot(
    column='NCI',
    cmap='coolwarm',
    legend=True,
    legend_kwds={'label': 'Neighbourhood Change Index'},
)
