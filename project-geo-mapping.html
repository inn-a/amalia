Urban Migration Mapping

Geo-spatial project · 2022–2024

This project combines administrative residence permit data with census records to produce high-resolution maps of migration flows across seven Northern European cities: Amsterdam, Antwerp, Brussels, Hamburg, Copenhagen, Stockholm and Oslo.

Using GeoPandas and QGIS, migration trajectories are disaggregated by country of origin, year of arrival and neighbourhood of settlement. The resulting dataset enables longitudinal comparison of spatial segregation patterns and their relationship to urban housing policy.

A key finding is the increasing concentration of recently arrived migrants in post-industrial peripheral zones, irrespective of city size — a pattern that cuts across national welfare regimes and challenges existing typologies of migrant integration.

Python · GeoPandas 
import geopandas as gpd
import pandas as pd
import matplotlib.pyplot as plt

# Load migration flow data and city geometries
flows  = pd.read_csv('data/migration_flows_2010_2022.csv')
cities = gpd.read_file('data/eu_cities_nuts3.geojson')

# Merge on city identifier
merged = cities.merge(flows, left_on='nuts_id', right_on='city_id')

# Compute net migration rate per 1000 inhabitants
merged['net_rate'] = (
    (merged['arrivals'] - merged['departures']) / merged['population']
) * 1000

# Plot choropleth
fig, ax = plt.subplots(1, 1, figsize=(14, 9))
merged.plot(
    column='net_rate',
    cmap='RdYlBu',
    legend=True,
    legend_kwds={'label': 'Net migration per 1,000 inhabitants'},
    ax=ax
)
ax.set_title('Net Migration Flows — Northern Europe, 2022', fontsize=14)
ax.axis('off')
plt.tight_layout()
plt.savefig('output/migration_map_2022.png', dpi=300)
